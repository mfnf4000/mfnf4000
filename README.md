## Directive I · Profile

- I work with **people, structure and operations**, and apply the same mindset to online communities and tooling.
- I design and maintain **Discord bot setups** to support moderation, automation and quality-of-life features.
- I value **clarity, documentation and predictable workflows** over flashy but fragile solutions.
- This GitHub profile serves as a record of ongoing experiments and long-term projects.
- 🤖 **Vibe coder** – I don't write code from scratch. I direct AI to build what I need, and I make sure it actually works.

---

## Directive II · Key Units (Bots)

- 🟥 **Commander Fox** – personal Discord bot focused on utility and structure within selected servers.
- 🟦 **Gojo** – moderation-oriented bot used in community environments to support staff workflows.

Both are treated as **long-term assets**: configuration, behavior and changes are monitored rather than left to chance.

## Directive III · Discord & Infrastructure

- Planning and iterating on **moderation flows**, permission structures and role hierarchies.
- Using bots to **standardize repetitive tasks** and reduce manual overhead for staff.
